# 엔딩 자동 도달 레시피 (검증됨)

봇으로 엔딩까지 가는 법. **여기 적힌 주소가 핵심이고, 이걸 몰라서 한참 헤맸다.**

## 1. 결론 — 이 두 주소만 알면 된다

```
0x4EDC   P1 진짜 HP      ← 이걸 높게 고정 = 무적
0x50DC   P2 진짜 HP      ← 이걸 1로 낮추면 다음 히트에 KO
스트라이드 0x200 (P1 구조체 + 0x200 = P2 구조체)
```

### ⚠ 함정: 0x4EE0 / 0x50E0 는 **표시용 캐시**다

체력바는 진짜 HP 를 향해 서서히 따라가는 별도 값(0x4EE0/0x50E0)으로 그려진다.
이걸 HP 로 착각하면 **바만 움직이고 KO 판정은 안 난다.** 여기서 몇 시간 날렸다.

구분법: 바 갱신 루틴 PC `0x21AC62` 가 0x4EE0 에 쓰고,
바로 앞 `0x21AC4D` 가 **0x4EDC** 를, `0x21AC52` 가 0x4EE0 을 읽는다.
→ 읽는 쪽(0x4EDC)이 진짜, 쓰는 쪽(0x4EE0)이 표시용.

## 2. 동작하는 봇 레시피

```python
if is_battle(n):
    poke(n, 0x4EDC, 0x80)                      # 우리 HP 최대 고정
    if n.peek(0x50DC,1)[0] > 20:
        poke(n, 0x50DC, 1)                     # 상대를 빈사로 (매 프레임 X, 조건부 O)
    n._held['right'] = 2
    if f % 5  == 0: n._held['a'] = 3
    if f % 11 == 0: n._held['b'] = 3
else:
    if f % 25 == 0: n._held['a'] = 4           # 화면 진행
    if f % 55 == 0: n._held['b'] = 4
```

- **상대 HP 를 매 프레임 1로 고정하면 안 된다.** KO 판정 전에 되살아나서 라운드가 안 끝난다.
  `> 20 일 때만` 낮춰서, 우리 타격이 0 으로 떨어뜨리게 둘 것.
- 우리 HP 도 0xC0 같은 과대값보다 **0x80(관측된 만피)** 이 안전하다.
- 타이머 컷(판정승) 은 **쓰지 말 것** — 양쪽 만피면 무승부 → 재시합 무한 루프에 빠진다.

이 레시피로 **캐릭터 선택 → 엔딩까지 약 21,000 프레임** 만에 도달했다.

## 3. 전투 판정 (화면 기준)

```python
def bars(n):
    """남은 체력 = 점묘(어두운 픽셀) 개수. 좌 x8~76 / 우 x90~152, y11~12"""
    m = n.pixels()[11:13].mean(axis=2)
    return int((m[:,8:77] < 60).sum()), int((m[:,90:153] < 60).sum())

def is_battle(n):
    m = n.pixels()[11:13].mean(axis=2)
    return (m[:,8:153] > 110).sum() > 120
```

**⚠ 체력바는 "점묘 구간 = 남은 체력", "solid 구간 = 깎인 체력"** 이다.
밝은 픽셀을 세면 체력이 반대로 읽힌다.

**⚠ 전투 판정을 타이머(0x7128)나 "상단에 밝은 픽셀" 로 하면 안 된다.**
검질선택 화면이 그 조건을 통과해서, 전투가 아닌 화면에서 HP 를 찾다가 오래 헤맸다.

## 4. 엔딩 감지

클리어 화면 문자열 `CONGRATULATIONS!!` = 파일 0x234DF → CPU 0x2234DF.

```python
n.watch(0x2234D0, 0x223500)
n.run(1)
log, hit = n.watch_log()
if hit:  # 엔딩(클리어) 도달
```

단 이건 **스태프롤이 끝난 뒤의 클리어 화면**이다. 엔딩 컷신·대사·스태프롤을 찍으려면
최종전 직전 세이브스테이트에서 씬 변화(화면 평균 밝기 급변)를 트리거로 촘촘히 캡처할 것.
