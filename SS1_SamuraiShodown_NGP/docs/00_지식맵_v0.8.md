## 2. 시스템 폰트 = BIOS 폰트 (H·I 의 열쇠, "압축"의 정체)

**압축은 없었다.** 메뉴 ASCII 폰트는 카트리지가 아니라 콘솔 BIOS 에 있다.

```
게임 코드 → 시스콜 디스패처 (파일 0x230C8~)
  · 슬롯번호 W → W*4
  · 벡터표 베이스 0x00FFFE00 로드   ← imm32 가 파일 0x230D1 에 평문
  · CALL [0xFFFE00 + slot*4]
슬롯 5 = VECT_SYSFONTSET (0xFF8D8A)
  · BIOS 1bpp 폰트 0x800B 를 2bpp 로 펼쳐 VRAM 타일 0x00~0x7F (0xA000~0xAFFF) 에 업로드
텍스트 = 타일맵 엔트리에 ASCII 그대로 ('P' = 0x2050, 0x2000 은 팔레트비트)
```

1bpp→2bpp **변환 업로드**라서 2bpp 패턴이 롬·에뮬 어디에도 없었다.
과거 LZSS 16종 + RLE 26,142곳 전수 탐색이 0건이었던 이유. **다시 하지 말 것.**

- 평문 뱅크 0x05291D 는 코드 전체(0x00~0x7F) 인덱스이며 **화면에 안 쓰인다** (원 문서가 맞았음)
- 벡터표 0xFFFE00 의 27엔트리 값 = beetle-ngp `bios.c` vectable 과 동일

### 가로채기 (gfx8.py, 릴리즈 [12])

디스패처의 벡터표 베이스 imm32(파일 0x230D1) 4바이트만 자유영역 사본(0x1D0000)으로
돌리고, 사본의 슬롯5만 22바이트 스텁으로 교체.

```
0x1D0100 스텁 (TLCS-900h, 손 어셈블 — 인코딩은 인터프리터 소스로 검증)
3A 3B 29                 PUSH XDE / PUSH XHL / PUSH BC
42 00 A0 00 00           LD XDE, 0x0000A000
43 00 02 3D 00           LD XHL, 0x3D0200      (폰트 블록 = 파일 0x1D0200)
31 00 08                 LD BC, 0x0800          (워드 수)
93 11                    LDIRW
49 5B 5A 0E              POP BC/XHL/XDE, RET
```

### ⚠⚠ 코드 예산 50칸 — 뺏으면 안 되는 코드

미번역 문자열(스태프롤·해금 안내)이 실제로 쓰는 코드는 **절대 한글에 배정하면 안 된다.**

```
예약: 0x21 !   0x22 "   0x26 &   0x27 '   0x28 (   0x29 )   0x2D -   0x2E .   0x40 ©
근거: "NORMAL"LEVEL / "ZANKURO" IS / LET'S TRY / C.YODA / KURARA.K /
      TSURU-CHANG / SUPERVISER(SNK) / BGM&SE / (SNK R&D DIV.2) / ⓒSNK 1998
```

v0.5 에서 © 를 덮어 `커SNK 1998`, v0.7 까지 `"` `'` `-` `.` 를 덮어
스태프롤이 `KURARA맨K`, `맨NORMAL맨LEVEL` 로 깨졌다. v0.8 에서 전수 조사 후 확정.

사용 가능: `0x23 0x24 0x25 0x2A 0x2B 0x2C 0x2F` + `0x3A~0x3F` + `0x5B~0x5F` + `0x60~0x7F` = **50칸**
현재 정확히 50/50 (여유 0). 문구를 늘리려면 다른 문구를 줄여야 한다.

## 3. 전투 HUD (I) — gfx9.py [13]

이름판은 그림 타일맵 레코드. 로더 PC 0x200501~0x200519, 라운드마다 재작성.

```
세트1: 78880 카즈키 788D9 한조 78931 우쿄 78978 시키 789C0 쥬베이 78A29 소게츠
       78A92 겐쥬로 78AFB 하오마루 78B64 나코루루 78BCD 리무루루 78C36 갈포드
       78C9F 시즈마루 78D08 아마쿠사 78D71 잔쿠로
세트2: 794B8 … 799A9 (같은 순서)
주변 : 78DDA=1P 78DFF=2P 78508=COM 78704~7885A=타이머 숫자 78E90/78F2E=PAUSE
       7859C~786BC=決殺死怒 한자
```

**⚠ 이름판 타일은 불투명**: 배경=3(검정) 글자=1(흰) 음영=2, **0은 투명**.
"최빈 비영값 = 잉크" 로 가정하면 반대로 뒤집혀 흰 판이 된다 (v0.5 사고).
`gfx9.plate_colors()` 가 배경=최빈, 잉크=1 로 잡는다.

## 4. 어트랙트 캐릭터명 (K) — gfx7.py [11]

```
마스터 디렉터리 file 0x1BA7CD u32le×16  entry15 = 0x311521 → 이름 스크립트 블록
캐릭터 디렉터리 file 0x1BA80D u32le×16  entry15 = 0x3B7389 = 이름 타일뱅크
스크립트 블록   file 0x111521 ~ 0x112709
  이름 레코드   [04 00][0x80|cnt][idxoff][hdr 2B][ (dx,dy)×cnt ]   dx,dy = 픽셀×2
  엔트리 표     u16le×cnt — 레코드 순서대로 연속 소비
                (앵커: 한조 레코드 @0x111687 → 엔트리 0x11208D 실측)
타일 뱅크       file 0x1B7389 + 타일번호×16   (2bpp 워드LE)
복사 루틴       PC 0x2005EE~0x200600
```
레코드 28개 = JP 14 + EN 14. 나머지 14레코드는 그래픽(타일 ≤0x7E, ≥0x1A0) → **불가침**.
패치는 구 이름 타일 0x7F~0x19F(289칸) 풀 재활용 + 엔트리·좌표 재작성 (210칸 사용, 병합 없음).

## 5. 타이틀 로고 4벌

```
일본어   A 08B410 (20×6)  B 08B8B0 (17×5)
영문1벌  A 08EA59 (20×6)  B 08F019 (19×5)
영문2벌  A 08DCB4 (19×6)  B 08E20E (17×5)
인트로 밝은판  맵 08AA44 (16×8=128×64)  타일 08A3C4 (104칸)   ← v0.7 에서 발견
```
**한 벌만 갈면 나머지에서 원문이 튀어나온다.** 밝은판은 v0.6 까지 일본어였다.

### 밝은판 주의 (gfx11.py [15])
- **VRAM 적재 시 타일 인덱스 +0x20 시프트** → 역추적 때 베이스가 0x200 어긋나 보인다
- 팔레트 역할이 본편과 반대: 밝은판 `0=배경 1=외곽선 2=몸통 3=안쪽`, 본편 `3=배경 0=외곽선 2=몸통 1=안쪽`
  (역할 판정은 **배경 인접도**로 정량화. 값 대 값 자동 대응은 실패한다)
- 값 단순 치환은 획이 뭉개짐 → 잉크 마스크 bbox 크롭 → 캔버스 맞춤 → 침식 3층

## 6. 그림 타일맵 공통 함정

1. **패치 뒤 `spec()` 재호출 금지** — `tile = map − n*16` 역산이라 타일 수가 변하면 어긋난다.
   되읽을 때는 **원본 롬 기준 타일 주소**를 쓸 것.
2. **압축(닮은 타일 강제 병합) 금지** — 획이 무너진다 (아마쿠사→마마쿠사, 카즈키→가즈키).
   예산 초과 시 글자를 줄이거나 x 위치를 1~4px 밀어라. 타일 경계에 맞물리면 고유 타일이 확 준다.
3. **PIL 로 Galmuri TTF 렌더 금지** — size=14 여도 획이 소실된다(카→가). **BDF 직접 파싱**할 것
   (`gfx7.bdf_line`). 난이도 화면도 이 문제였고 v0.6 에서 gfx10 으로 재렌더했다.

## 8. 트레이싱 코어 (이 프로젝트의 핵심 도구)

`beetle-ngp-tracing.patch` 를 libretro 코어에 적용하면 생기는 것:

| API | 용도 |
|---|---|
| `retro_dbg_watch(lo,hi)` / `log_count/pc/ad` | 읽기 워치포인트 (자료구조 추적) |
| `retro_dbg_wwatch(lo,hi)` / `wlog_*` | 쓰기 워치포인트 (누가 쓰는지) |
| `retro_dbg_iwatch(lo,hi)` / `ilog_get` | 명령어 트레이서 (PC + 레지스터 8개) |
| `retro_dbg_peek` / `peek_block` | RAM/VRAM 임의 읽기 |
| `retro_dbg_poke` | 임의 쓰기 (치트·실험) |

`ngp_harness.py` 가 ctypes 로 직결. 화면이 **원본 해상도 160×152 로 바로** 나와서
mednafen+Xvfb 처럼 3배 축소 복원·창 오프셋 탐색이 필요 없다.

- 명령어 페치도 loadB 를 지나므로 **데이터 영역만 감시**할 것
- 세이브스테이트 지원, `language='japanese'|'english'` 로 본체 언어 전환

## 9. 반복 금지 목록

1. **압축 해독 시도** — 압축은 없다 (2장). LZSS/RLE 전수는 이미 소진.
2. **캐릭터 이름 스프라이트 재사용** — 이름표는 프리렌더 타일, 대사는 8×8 폰트 경로. 렌더러가 다름.
3. **평문 뱅크 0x05291D 를 화면 폰트로 착각** — 안 쓰인다.
4. **예약 코드(`! " & ' ( ) - . ©`) 를 한글에 배정** — 스태프롤이 깨진다 (2장).
5. **`pkill -f <스크립트명>`** — 명령줄에 그 문자열이 있으면 **자기 셸을 죽인다**. `pkill -x python3`.
6. **TTF 렌더** — BDF 를 쓸 것.
