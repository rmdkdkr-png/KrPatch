# SS1 — "압축"의 정체와 H·I 해결 (v0.5 → v0.6)

## 0. 결론 한 줄

**압축은 없었다.** 메뉴·타이틀 ASCII 폰트는 콘솔 **BIOS 내장 폰트**(1bpp)를
시스콜로 VRAM에 펼친 것이고, HUD 이름은 평범한 그림 타일맵 레코드였다.

## 1. 시스템 폰트 경로 (실측 사슬)

```
게임 코드 → 시스콜 디스패처 (파일 0x230C8~)
  · 슬롯번호 W → W*4  (SLL 두 번)
  · 벡터표 베이스 0x00FFFE00 로드  ← imm32가 파일 0x230D1 에 평문
  · CALL [0xFFFE00 + slot*4]
슬롯 5 = VECT_SYSFONTSET (0xFF8D8A, BIOS)
  · BIOS 1bpp 폰트 0x800B를 2bpp로 펼쳐 VRAM 타일 0x00~0x7F에 업로드
텍스트 = 타일맵 엔트리에 ASCII 그대로 ('P' = 0x2050, 0x2000은 팔레트비트)
```

1bpp→2bpp 변환 업로드라 2bpp 패턴이 롬·에뮬 어디에도 없었던 것.
평문 뱅크 0x05291D는 코드 전체(0x00~0x7F) 인덱스이며 화면에는 쓰이지 않음.

## 2. H 해결 (gfx8.py — [12]단계)

디스패처의 벡터표 베이스 즉치값(파일 0x230D1)만 자유영역 사본(0x1D0000)으로 바꾸고,
사본의 슬롯5만 스텁으로 교체. 스텁(0x1D0100, TLCS-900h 22B 손 어셈블):

```
3A 3B 29 / 42 00 A0 00 00 / 43 00 02 3D 00 / 31 00 08 / 93 11 / 49 5B 5A 0E
(PUSH ×3 / LD XDE,0xA000 / LD XHL,폰트 / LD BC,0x800워드 / LDIRW / POP ×3, RET)
```

폰트 블록(0x1D0200) = BIOS 폰트 2bpp 복제 + 한글 57음절(Galmuri7 BDF, 잉크3).
코드 예산 57칸: 0x60~0x7F + 0x5B~0x5F + 0x3A~0x3F + 0x22~0x2F.
A~Z·0~9·공백·'!'(0x21)·©(0x40)는 불가침 — 미번역 문자열이 알파벳을 쓴다.

## 3. I 해결 (gfx9.py — [13]단계)

HUD 이름판 = 그림 타일맵 레코드, 14명×2세트:
세트1 0x78880~0x78D71 / 세트2 0x794B8~0x799A9 (카즈키 한조 우쿄 시키 쥬베이 소게츠
겐쥬로 하오마루 나코루루 리무루루 갈포드 시즈마루 아마쿠사 잔쿠로 순).
주변: 1P/2P/COM/타이머 숫자(8×16)/決殺死怒 한자/PAUSE.

⚠ 이름판 타일은 **불투명**: 배경=3(검정, 최빈값), 글자=1(흰), 2=음영, 0=투명.
잉크에 최빈값을 쓰면 반전 사고("흰 판") — v0.6 plate_colors()로 수정.

## 4. 함정 목록 (신규)

1. harness 버튼 매핑: beetle-ngp는 RETRO B(id0)→NGP A, RETRO A(id8)→NGP B.
2. 0x40(©)·0x21(!)은 실사용 문자 — 한글 슬롯 금지.
3. 명령어 트레이서(retro_dbg_iwatch/ilog)로 디스어셈블러 없이 기계어 의미 복원 가능.
4. 시스콜 콜사이트는 롬에 평문으로 없음 — 공용 디스패처 하나만 만지면 전 시스콜 가로챔.
5. TTF 렌더 뭉개짐: 난이도 화면 라벨도 피해자 → gfx10.py([14]단계) BDF 재렌더.

## 5. 남은 것

FAIR & SQUARE(J), 받침 타이핑(L), HITS 미니폰트, 決殺死怒 한자,
LET'S TRY 계열 문자열, 어트랙트 시키 글자 크기, TTF 화면의 BDF 전환.
