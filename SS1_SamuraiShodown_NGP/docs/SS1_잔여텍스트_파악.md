# SS1 남은 텍스트 전수 조사

v0.2 기준. 스토리 대사 184문장과 타이틀 로고는 끝났고, **그 외 텍스트가 어디에 어떤 방식으로 박혀 있는지** 전부 훑었다.

## 이 게임의 텍스트는 세 가지 방식으로 그려진다

| | 방식 | 현황 |
|---|---|---|
| **1** | **대사 폰트** — 8×16 한글 조판, 글리프 슬롯 217칸 | 한글화 완료. 단 **미번역 블록 하나 발견** |
| **2** | **ASCII 8×8 폰트** — 폰트 `0x05291D`, **타일번호 = ASCII 코드**. 문자열은 롬에 널종결 ASCII | 전부 원문 |
| **3** | **통짜 그림 타일** — 한자·가타카나가 그림으로 박힘 (로고와 같은 구조) | 전부 원문 |

방식 2가 특이하다. 타일맵에 ASCII 코드를 그대로 써 넣으면 폰트 뱅크의 해당 타일이 찍힌다.
즉 **문자열만 고치면 화면이 바뀐다** — 대신 한 글자 = 8×8 한 칸이다.

## 2. ASCII 8×8 폰트로 그려지는 것

| 주소 | 내용 |
|---|---|
| `0x009248` | PRESS A BUTTON |
| `0x0231E8` | 1P MODE / SURVIVAL / VS MODE / GAME OPTION |
| `0x02320F` | VS WAIT / OPTION MODE / LEVEL / POINT / TIME / VS/POINT / VS/TIME / SE / BGM / EXIT |
| `0x00C633` | EASY / NORMAL / HARD |
| `0x011291` | SELECTABLE!! / ENTER THE COMMAND / AT CHARACTER RAN-DOM SELECT |
| `0x023343`~`0x0234D2` | 스탭롤 (PROGRAM, CHARA DESIGN, PLAN, DEBUG, DIRECT, PRODUCE + 이름들) |
| `0x0234DF` | CONGRATULATIONS!! / CLEAR! |

화면 배치는 이렇다(타일 행 번호).

```
타이틀 메뉴          옵션 화면
10  ...TM             2  OPTION MODE
12  1P MODE           4  LEVEL    NORMAL
13  SURVIVAL          5  POINT       2
14  VS MODE           6  TIME       60
15  GAME OPTION       7  VS/POINT    2
18  @    1998         8  VS/TIME    60
                     10  SE         00
                     11  BGM        00
                     13  EXIT
```

**여기가 이번 작업의 갈림길이다.** 한글 한 글자는 세로 2칸(8×16)을 써야 읽히는데
이 화면들은 **한 줄에 한 칸**만 쓴다. 메뉴 4항목이 12~15행에 붙어 있어 두 줄씩 쓸 자리가 없다.

전부 **로고와 똑같은 구조**(타일 뱅크 + 타일맵)라 이미 만든 도구(`ss1_logo.py`)로 뽑고 넣을 수 있다.
타일 예산도 같은 방식으로 계산·압축된다.

## 제안하는 순서

1. **초필살기 대사 14문장** — 오늘 바로 끝낼 수 있다. 위험 없음.
2. **그림 텍스트** — 검질/레벨 화면, 캐릭터 이름, 라운드 콜. 로고 파이프라인 재사용.
   외주 편집기도 이 화면들용으로 찍어낼 수 있다.
3. **ASCII UI** — 메뉴 방식을 정한 뒤 착수.

## ASCII UI 처리 방안 (택일 필요)

**가) 8×8 한글 폰트**
ASCII 폰트 뱅크의 안 쓰는 코드에 한글 음절을 8×8로 새로 그려 넣고 문자열을 그 코드열로 바꾼다.
롬 구조를 전혀 안 건드려 가장 안전하고, 메뉴처럼 짧은 단어(1인 대전 / 서바이벌 / 게임 설정)는 읽힌다.
다만 받침 있는 글자는 빽빽해진다.

**나) 코드 패치로 두 줄 출력**
문자열 출력 루틴을 고쳐 한 항목을 두 행에 걸쳐 찍게 만든다. 품질은 대사와 동급(8×16).
대신 메뉴 항목 간격·커서 위치까지 같이 손봐야 하고, 실기 리스크가 생긴다.

**다) 메뉴만 그림으로 교체**
타일맵에 한글 그림 타일을 직접 박는다. 품질은 최상이지만 항목별 위치·커서 처리를 따로 맞춰야 한다.

**라) 영문 그대로 두기**
1P MODE / SURVIVAL 같은 건 그대로도 통한다. 스탭롤도 원문 유지가 자연스럽다.
