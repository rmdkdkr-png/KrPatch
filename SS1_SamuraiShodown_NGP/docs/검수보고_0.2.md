## 이번에 고친 것

### 1. 영문 타이틀 로고 정렬 (본건)

영문 2벌 본로고 블록이 152px 인데 캔버스는 160px 이라 8px 이 모자랍니다.
전에는 **좌우 4px 씩 잘라 가운데 맞춤**으로 임의 처리했고, 그 탓에 본로고만
4px 밀려 부제와 어긋났습니다. 왼쪽 붓자국도 잘렸습니다.

롬 데이터끼리 대조해 원본 2벌 블록이 1벌 블록의 **가로 8px 지점부터** 잘라낸 것임을
확정했고(본로고·부제 모두 dx=8), 각 블록이 덮는 화면 구간을 캔버스에서 그대로
떠오도록 바꿨습니다.

    1벌 본로고(160px) → 캔버스 x  0~159
    1벌 부제  (152px) → 캔버스 x  8~159
    2벌 본로고(152px) → 캔버스 x  8~159   ← 수정 (전: 4~155)
    2벌 부제  (136px) → 캔버스 x 16~151

1벌 부제도 같이 정리했습니다. 전에는 136px 를 152px 블록 가운데 놓고 남는 좌우를
검정으로 채우느라 팻말 오른쪽 끝이 몇 px 잘려 있었는데, 이제 잘림이 없습니다.

### 2. 빌드 스크립트 버그 (같이 발견)

`gfx3.patch()` 가 명령줄로 넘긴 로고 JSON 을 무시하고 GPT 경로를 하드코딩해
쓰고 있었습니다. **다른 로고로 빌드하면 일본어판만 바뀌고 영문판은 GPT 로 남는**
버그입니다. 이번 판은 로고가 GPT 라 결과에는 영향이 없었지만, 인자를 받도록 고쳤습니다.

## 일부러 뺀 것

**메뉴·옵션 ASCII UI** 와 **전투 HUD 히트 카운터** 는 꺼져 있습니다.

화면에 쓰이는 폰트가 카트리지 안에 **압축 저장**돼 있어서, 평문 폰트 뱅크
(`0x05291D`, `0x015A00`)를 고쳐도 화면이 바뀌지 않습니다. 켜면 메뉴가
`1 g  h i` 같은 쓰레기가 됩니다. 실기 실험으로 확인한 내용이며 근거는
`ASCII폰트_최종결론.md`(직전 인계분)에 정리해 뒀습니다.
