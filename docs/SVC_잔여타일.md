# SVC MotM 한글판 v17.2 — 잔여 원본 타일 조사

`tools/tiletool/`로 조작 경로 9화면을 관측하고, 원본 롬 `SNK Vs Capcom - Match of The
Millennium (JUE) [!]`와 대조한 결과다. 조사일 2026-08-24.

판정은 주소가 아니라 **내용**으로 한다. 화면에 뜬 타일의 16바이트가 원본 롬 어디에도
없으면 새로 그린 타일이다. (4MB 롬에서는 같은 타일이 여러 주소에 중복돼 주소 비교가 흔들린다.)

```bash
python3 tools/tiletool/observe.py SVC_kr_v17.2.ngc rec_svc/ screens_svc.json
python3 tools/tiletool/diffmap.py rec_svc/ 원본.ngc SVC_kr_v17.2.ngc \
        --lines 줄/ --min-run 4 --csv 남은것.csv
```

### 우선순위

1. ~~**타이틀 로고와 안내문**~~ — **머리글·안내문은 처리했다** ([`tools/svc/`](../tools/svc/)).
   「頂上決戦」→「정상결전」(타일맵 32타일), 「Aボタンを おし くださ」→「A버튼을 눌러 주세요」(스프라이트 12타일).
   큰 로고 「最強ファイターズ」는 타일 119장짜리 스타일 아트라 남아 있다 — 사람이 그려야 한다
2. **영문 머리글 4종** — `MAIN MENU` / `GAME SELECT` / `STYLE SELECT` / `PLAYER SELECT`.
   항목은 한글인데 머리글만 영문이라 눈에 걸린다
3. **캐릭터 이름판** — `KYO` 등. 32명분이라 분량이 가장 크다
4. 저작권 줄·HUD·배경은 번역 대상이 아니다

## 한계

- `--lines`의 "원본 잔여"에는 **그림 타일도 섞인다.** 미번역 글자만 자동으로 걸러내지는 못한다.
  줄 그림을 눈으로 훑어 고르는 단계가 남는다
- 관측 9화면 밖(스파링·올림픽·통신 대전·엔딩 등)은 아직 안 봤다.
  `screens_svc.json`에 경로를 추가하면 그만큼 커버리지가 늘어난다
